# Victoria Hotel Apartment

Demo website for **Victoria Hotel Apartments** in Sarbet, Pushkin Square, Addis Ababa.

Built with Next.js 15, TypeScript, and Tailwind CSS. Includes public booking flows, room pages, reviews, contact, and a booking-only admin demo at `/admin`.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run start` — run production server
